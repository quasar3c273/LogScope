# LogScope

LogScope помогает понять, где на сайте чаще всего возникают ошибки сервера. Он читает лог запросов строка за строкой, считает ответы с кодами от 500 до 599 для каждого пути и выводит самые проблемные пути первыми.

## Первый запуск

Понадобится Python 3.9 или новее. Дополнительных библиотек у проекта нет. Открой терминал в папке проекта и запусти команду на готовом примере:

```sh
python -m logscope example.jsonl
```

Получится такой отчёт:

```text
2       /checkout
Invalid records: 1
```

Первая строка означает, что на запросы к `/checkout` сервер дважды ответил ошибкой. Вторая показывает, что одну строку лога программа пропустила. В файле [example.jsonl](example.jsonl) это строка со словом `broken`.

## Как проверить свой лог

Сохрани лог в кодировке UTF-8. Каждая строка должна содержать отдельный JSON-объект. В поле `path` укажи путь, начинающийся с `/`, а в `status` — целое число от 100 до 599. Например:

```json
{"path": "/login", "status": 503}
```

Если файл называется `access.jsonl`, команда ниже покажет три пути с наибольшим числом серверных ошибок. По умолчанию LogScope выводит до пяти путей.

```sh
python -m logscope access.jsonl --top 3
```

## Как запустить тесты

```sh
python -m unittest -v
```

Тесты проверяют пустой файл и смесь корректных и повреждённых записей. Если всё в порядке, в конце появится `OK`.
